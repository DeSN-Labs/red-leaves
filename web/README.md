# 红叶 Web 客户端原型

TypeScript + React + Vite，Node.js 22.12+。独立构建，不依赖 Rust 启动。

```sh
cd web
npm ci
npm run dev
```

默认入口 http://127.0.0.1:5173。`npm run check` 检查类型，
`npm run build` 产出 `dist/`，`npm run preview` 预览构建产物。

## 当前功能

钱包登录页、左侧导航的关注内容首页、搜索与分类、创作者筛选、内容详情和当前会话的演示点赞／收藏。
可请求兼容 EIP-1193 的浏览器扩展钱包公开地址；取消、缺失钱包和重复请求有错误提示。
账户、网络变化或钱包断开后返回连接页。页面退出仅清除本应用状态，不撤销钱包站点权限。

钱包连接不是签名认证，尚未查询 Base Sepolia 链上绑定、连接 NAS 或发送交易。
演示身份不会连接钱包；所有帖子与统计均为演示数据，收藏不会下载到 NAS，刷新后重置。
演示图片来自 Unsplash，字体来自 Google Fonts，需要外网，真实内容后续通过节点 API 获取。
不提供算法推荐；正式手机 App、安全会话和设备授权需另行实现。
