# 红叶 Web 客户端原型

TypeScript + React + Vite，Node.js 22.12+。独立构建，不依赖 Rust 启动。

```sh
cd web
npm ci
npm run dev
```

默认入口 http://127.0.0.1:5173。`npm run check` 检查类型，
`npm run build` 产出 `dist/`，`npm run preview` 预览构建产物。

## 当前功能

EOA 钱包签名登录页、左侧导航的关注内容首页、搜索、关注动态卡片网格与创作者单列时间线、创作者筛选、内容详情和当前会话的演示点赞／收藏。
可请求兼容 EIP-1193 的浏览器扩展钱包公开地址；取消、缺失钱包和重复请求有错误提示。
账户、网络变化或钱包断开后返回连接页，并尝试撤销服务端会话；失败时提示会话到期失效。退出不撤销钱包站点权限。

需先启动 NAS（仓库根目录 `cargo run -p red-leaves`）。Web 默认直接请求 `http://127.0.0.1:3000/api`，后端支持 CORS；钱包需选择 Base Sepolia。
配置放 `.env.profile`（模板见 `.env.example`），Vite 配置始终加载 `.env.profile` 的公开 API／合约地址，兼容 IDE 默认 `development` 启动；配置 `VITE_API_BASE_URL` 及 `VITE_USER_REGISTRY_ADDRESS` 后重启，生产构建时设置实际 API 的 HTTPS 地址。
已接入 SIWE 挑战签名认证，使用 NAS 设置的 HttpOnly Cookie，前端不保存令牌；刷新后自动验证会话及钱包地址和网络，无须重新签名。会话有效期 1 小时，退出时撤销并清除 Cookie。API 请求携带 credentials 和自定义来源保护头，仅允许配置的 Web origin；生产使用 HTTPS 同站点部署或同源反向代理，见[钱包登录](../docs/wallet-login.md)。
首次登录选择具体钱包后会记住公开提供者标识，刷新、发帖和资料操作复用同一个钱包；登录页可主动选择其他钱包。偏好不包含令牌，Cookie 会话及钱包地址／网络校验仍有效。
钱包登录成功即将当前 API 服务视为已认证的 NAS，侧栏及“我的 NAS”展示连接状态和 API 地址，可手动检查会话。
发布按钮先验证 NAS 会话，再进入真实图文／视频发帖表单。支持标题加文字、图片或视频，可选择广播、关注、关注者、互关好友、指定人；指定人支持勾选好友／关注钱包或手动填地址，明确签名确认后保存；帖子不设置价格，签名保存后直接排队投递。“我的关注”管理签名并同步到目标 NAS 的关系，“关注动态”按接收偏好展示真实 NAS 数据。媒体上传、加密存储及按受众读取已实现；已接入范围投递和 Cookie 认证的 SSE 实时刷新，我的发布显示重试／保存／公告状态；需要按[推送说明](../docs/scoped-delivery.md)配置可达节点或共同中继。演示模式继续使用独立演示数据。
登录后点击左下角钱包进入个人资料页查看登记状态，从认证接口验证节点类型并获取 PeerId，通过钱包查询链上登记。未登记且确认是 NAS 节点时显示 `Register profile` 按钮，用户主动展开昵称／公钥表单，再确认钱包交易；不会自动弹窗或发送交易。等待两区块确认及字段核对。查询失败显示具体错误和重试入口，旧服务缺少身份接口时提示重启 NAS。不会自动提交或覆盖已有登记，认证成功不代表已获得用户数据权限。
首次登记主动请求 NAS 准备 X25519 公钥，私钥保存在 NAS。旧浏览器密钥不自动迁移；可在个人资料页主动更新链上公钥，需另行备份 NAS 主密钥及用户密钥文件。流程、配置及限制见[首次绑定 NAS](../docs/nas-registration.md)，认证接口见[钱包登录](../docs/wallet-login.md)。
`npm test` 使用模拟钱包/API 验证登录与退出流程；尚未执行真实钱包扩展端到端验证。
内容列表保留数据源返回顺序，前端不排序；当前节点 API 按保存时间和 ID 倒序返回内容。
侧栏新增“消息通知”入口，点击进入功能待实现的占位页；当前不提供通知数据、未读计数或消息处理。
演示身份不会连接钱包；演示模式中的帖子与统计为演示数据，收藏不会下载到 NAS，刷新后重置。
演示图片来自 Unsplash，字体来自 Google Fonts，需要外网，真实内容后续通过节点 API 获取。
不提供算法推荐；正式手机 App、安全会话和设备授权需另行实现。

图文／视频发布、付费合约部署及加密／接收边界见[发帖说明](../docs/posting.md)。本地集成检查可在构建 NAS 和合约后执行 `node --experimental-strip-types tests/publishing.anvil.mjs`，仅使用临时 Anvil 账户。

个人资料入口位于侧栏左下角钱包按钮，昵称登记、NAS 绑定和应用公钥管理集中在该页。图片／视频限制、草稿恢复及权限边界见[发帖说明](../docs/posting.md#内容形式卡片与受众)。

多节点／中继集成验证：`node --experimental-strip-types tests/delivery.anvil.mjs`，需先构建 NAS 和 Foundry 合约，仅使用临时 Anvil 账户。

真实 NAS 帖子详情支持签名点赞／取消点赞、按需刷新作者统计，以及作者限制／恢复单帖点赞访问；作者不可用时不显示旧统计，离线变更由 NAS 队列重试。评论与真实收藏暂未接入，见[点赞同步](../docs/likes.md)。

作品发布后支持五档访问权限；新拉取及点赞同步使用最新权限，其他 NAS 的已缓存数据不受影响。评论尚未实现。见[作品访问权限](../docs/post-access.md)。
