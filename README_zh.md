# red-leaves （红叶）
去中心化社交网络

## 项目愿景
创建一个区块链去中心化社交网络开源项目，实现用户可以在这个社交网络上自由创作并获取收益，自由查看他人创作的内容，自由打赏或购买数字化资产，涉及收益部分由区块链结算，类似抖音或者小红书，但是创作者的收益没有平台抽成，创作的内容不受审查，获取的收益可以变现，整个网络没有官方广告。
项目需要由如下几部分构成：
1. 一个L2区块链网络，发行自己的代币，或者用已有的L1代币桥接过来，实现安全和结算；
2. 一个P2P社交网络，用户创作的内容可以定向或不定向广播，其它用户可以自由选择接收或不接收广播内容；
3. 一个社交网络客户端，可以是手机app、web页面或其它形式，实现对社交网络内容的展示和交互。

这个仓库是社交网络部分，主要实现社交信息的创作、传播部分。

## 功能方案
包含以下功能：
1. 用户可以用钱包地址作为身份加入网络，无需注册等操作；
2. 网络会有大量的区块链节点作为应用客户端的服务器；
3. 用户可以凭钱包地址身份在不同服务器之间切换，连接不同的服务器，但是需要设置一个可以信任的常驻服务器，用于处理自己相关的网络数据，切换到其它服务器后社交能力应该做一些限制；
4. 用户可以在该网络关注别的用户、和其它用户单聊、群聊，可以发表自己创作的内容，可以评论其他人发布的内容；
5. 用户创作的内容可以选择发布范围，如全网/关注的人/好友/特定账号/私密等；
6. 用户可以选择自己接收的内容范围，如任意广播内容/关注的人/好友等，如果某个用户被加入自己的黑名单，则再也不会被动看到该用户的内容；
7. 用户在阅读别人创作的内容时，可以打赏；
8. 用户可以设置自己创作的内容需要付费才能查看；
9. 用户可以在社交网络直播，可以设置为收费直播或不收费直播；
10. 所有的结算都使用我们自己的链的token；
11. 用户除了全网广播外的所有内容都需要加密，传输给特定用户的内容需要用对方的公钥加密；
12. 需要限制传播范围的内容可以用AES加密方式；
13. 网络允许数字资产的交易，将资产加密后，为买家提供解密密钥，有人购买后，将密钥用购买方的公钥加密后提供给买方，不提供退款等操作，如果数字资产体积较大，需要托管给网络上特定的节点；
14. 网络需要提供不同角色的节点，如存储提供节点、流量中继节点、公开服务器节点等，这些节点可以通过提供服务获取报酬；
15. 用户在网络上消费流量一般需要付费，设计中用户创作的内容，除了托管到存储节点的，都只保存在常驻服务器，一般可能是在NAT后面的NAS设备，用户查看内容需要使用中继服务的，则需要付费；
16. 创始团队保留铸币权，从而可以获取报酬，但是需要做出规则限制；
17. 用户把内容托管到第三方节点，一般需要付费，托管节点可以设置托管费用；
18. 所有收益没有平台抽成；

## 技术方案
考虑使用 https://github.com/Sovereign-Labs/sovereign-sdk.git 来实现
1. 考虑所有节点间的p2p连接只使用一条，兼顾L2的p2p和内容传播的p2p；
2. 需要分析哪些内容要上链，哪些内容不上链；

## 方案的优势
1. 创作者的收益无平台抽成
2. 创作的内容不受审查
3. 内容的传播由用户自由选择
4. 创始团队只持有一定量的代币，只有保持代币价值稳定才能获得收益，与网络使用者利益一致
