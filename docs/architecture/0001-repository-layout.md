# ADR-0001：单仓库与独立工程

状态：采用

节点、协议库、Web 和合约放在同一个仓库，独立构建及部署。
Rust 使用 workspace，先拆 protocol 和 node；节点内部以模块组织，暂不继续拆 crate。
Web 使用 TypeScript + React + Vite 构建静态客户端原型，后续通过版本化客户端 API 连接节点，不访问数据库。
管理接口和用户接口分别授权，P2P 协议与客户端 API 分别维护版本。
未来接口稳定后采用规范生成客户端类型，不手工复制两套定义。
NAS 通过 RPC 使用 Base Sepolia，无需运行 L2 全节点。

main 保持可构建，使用短期功能分支和 PR；协议、实现、相关测试在同一 PR 更新。
应用锁文件入库；真实密钥、数据库与构建产物不入库。
节点、Web 产物及合约部署记录分别发布；链和合约地址通过配置选择。
